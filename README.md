# slova-topics

Дефолтний каталог тем для речень-завдань у чаті Slova. Один файл `topics.json`, не залежить від мови.

Застосунок завантажує його з `main` один раз (поки `topicsSeeded=false`) і далі працює з власною копією у redux.

- `version` — число, бампати при зміні вмісту.
- `topics[].id`, `topics[].items[].id` — не змінювати (на них посилаються вибрані юзером підтеми).
- `items[].text` — англійською, саме цей рядок іде в промпт.
